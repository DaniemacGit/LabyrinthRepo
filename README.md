# Rollio – Physics-Driven Mobile Game (Unity)

Rollio is a physics-driven mobile game built in Unity where players tilt their device to guide a ball through obstacle-filled maps and drop it into a finish hole to progress through increasingly challenging levels. The game emphasizes intuitive motion controls, clean UI navigation, and scalable architecture for future expansion.

---

## Gameplay Overview

- Tilt-based controls using mobile device sensors  
- Navigate around obstacles and terrain to reach the goal  
- Complete levels to unlock more challenging stages  
- Optimized for smooth mobile gameplay

## ✨ Core Features

- Physics-based gameplay using Unity’s physics engine  
- Multi-screen UI flow  
  - Home → Levels → Gameplay  
  - Settings and Exit screens  
- Level selection with playable stages  
- Firebase integration  
  - User authentication and account creation  
  - Persistent player data  
- Player profiles and stats  
  - Level completion tracking  
  - Star ratings / progress indicators  
- Modular design for easy feature expansion
